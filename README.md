# TITAN STARK AI — Owner-Controlled Portal

بوابة عربية داكنة ومتجاوبة لـTITAN STARK AI وشركة TITAN Digital، مبنية باستخدام React وTypeScript وVite ومنشورة على GitHub Pages. تتضمن مولد مواقع محليًا واضح المصدر، ومركز مالك للنماذج والأصوات وذاكرة الأوامر، مع الحفاظ على المشاريع وبيانات الشركة.

تفاصيل الفحص وما لم يُنفّذ بعد موثقة في [AUDIT.md](AUDIT.md).

- الموقع: https://abdallanai369-lgtm.github.io/abdullah-cv/
- المستودع: https://github.com/abdallanai369-lgtm/abdullah-cv
- محرر المحتوى: https://app.pagescms.org/

## تعديل الموقع بسهولة

لم يعد المشروع يحتاج إلى Supabase أو قاعدة بيانات أو مفاتيح خارجية. نستخدم **Pages CMS** مع تسجيل دخول GitHub:

1. افتح https://app.pagescms.org/ وسجّل الدخول بحساب GitHub.
2. في أول مرة، وافق على تثبيت Pages CMS وامنحه الوصول إلى مستودع `abdullah-cv`.
3. افتح المستودع ثم اختر **محتوى موقع الشركة**.
4. عدّل البيانات أو المشاريع أو المهارات، ثم اضغط **Save**.
5. ينشئ Pages CMS عملية Commit في GitHub، وينشر GitHub Actions التعديل تلقائيًا، عادةً خلال دقيقة أو دقيقتين.

يمكن الوصول إلى هذه التعليمات أيضًا من رابط **لوحة التحكم** أسفل الموقع.

### من يمكنه التعديل؟

الزوار لا يمكنهم تعديل الموقع. التعديل الفعلي يتطلب حساب GitHub يملك صلاحية الكتابة على المستودع، مثل حساب المالك أو أي Collaborator تضيفه بنفسك.

## مكان المحتوى والإعدادات

```text
content/cv.json       كل بيانات الموقع
.pages.yml            حقول محرر Pages CMS باللغة العربية
public/media/         الصور والملفات المرفوعة من المحرر
.github/workflows/    النشر التلقائي إلى GitHub Pages
```

بعد أي Commit على فرع `main` يبدأ النشر تلقائيًا. يمكن متابعة العملية من تبويب **Actions** في المستودع.

## التشغيل محليًا

```bash
npm install
npm run dev
```

- الموقع: العنوان الذي يظهر في الطرفية.
- صفحة تعليمات المحرر: `admin.html` بجوار عنوان الموقع.

لبناء نسخة الإنتاج:

```bash
npm run build
npm run preview
```

## TITAN AI وGemini

تتضمن الواجهة `SmartStudio` وضعين للمالك والعميل: محادثة، إنشاء موقع كامل، تعديله، معاينته، وتنزيل HTML أو ZIP. عند عدم ضبط الخادم يعمل المولد المحلي وتظهر النتيجة بوضوح بأنها «قالب محلي»، دون ادعاء استخدام Gemini.

لتفعيل Gemini لا تضع مفتاح API في هذا المشروع أو داخل APK. استخدم الخادم الوسيط في مشروع `titan-backend`، ثم اضبط عنوانه وقت البناء:

```bash
VITE_TITAN_AI_ENDPOINT=https://your-worker.workers.dev npm run build
```

يمكن للمالك أيضًا إدخال العنوان من إعدادات التطبيق. النشر يتطلب رمز مالك مستقلًا، ويحفظه تطبيق أندرويد مشفرًا في Android Keystore. المواقع التي يوافق المالك على نشرها تُحفظ في `public/sites/<id>/index.html` وتخرج مع نسخة GitHub Pages التالية.

الملفات الأساسية:

```text
src/SmartStudio.tsx         المحادثة والإنشاء والتعديل والمعاينة والنشر
src/StarkCommandCenter.tsx  مركز المالك والنماذج والأصوات والذاكرة
src/stark.css              تصميم البوابة ومركز القيادة المتجاوب
src/androidBridge.ts        جسر أندرويد مع رمز جلسة للصفحة الموثوقة فقط
vite.config.ts             توليد SEO من مصدر المحتوى نفسه
```

لا تُرسل معاينات المواقع إلى أصل الصفحة، وتعمل داخل iframe بلا `allow-same-origin`. أوامر الجسر الحساسة تتطلب رمز جلسة عشوائيًا لا تستطيع المعاينة المولدة قراءته.

## TITAN Commander على أندرويد

يتضمن تطبيق 4.0 أوامر نظام للمالك: فتح تطبيقات وروابط وبحث المتصفح، والتنقل والنقر والكتابة والتمرير عبر Accessibility بعد تفعيلها يدويًا. زر Quick Settings يستدعي المساعد من خارج التطبيق، والتذكيرات تعمل عبر WorkManager في الخلفية. Voice Lab يعرض الأصوات المثبتة ويعاينها، ويمكن للمالك مراجعة ذاكرة الأوامر وتصحيحها وحذفها وتصديرها.

يمكن تعليم اختصارات محلية بصيغة «لما أقول… اعمل…»، وتحفظ في ذاكرة الجهاز دون تعديل كود التطبيق. أوامر كلمات المرور ورموز التحقق محظورة، والضغط على إجراءات مثل الحذف أو الإرسال يتطلب تأكيدًا ظاهرًا. لا تعمل هذه الأوامر في وضع العميل.
